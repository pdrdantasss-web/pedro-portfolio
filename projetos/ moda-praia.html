Moda Praia

Projeto de e-commerce desenvolvido para uma loja de moda praia.

Sobre o projeto

Este projeto foi desenvolvido utilizando HTML, CSS, JavaScript e uma API para gerenciamento dos dados da aplicação.

Tecnologias utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • Python
  • FastAPI
  • SQLite

Funcionalidades

  • Catálogo de produtos
  • Sistema de usuários
  • Cadastro e login
  • API REST
  • Gerenciamento de produtos
  • Banco de dados
